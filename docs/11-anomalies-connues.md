# Anomalies connues

**Objet.** Ce document rassemble les bugs, incohérences et écarts au cahier des charges relevés en relisant le code pendant la rédaction de la documentation (12 octobre 2026). Il sert de carnet de travaux : chaque entrée indique l'emplacement dans le code et une piste de correction. **Aucune de ces anomalies n'a été corrigée.** Les doublons entre documents ont été fusionnés.

La colonne « Revérifié » vaut « oui » quand l'anomalie a été recontrôlée dans le code au moment de la consolidation ; les autres entrées viennent d'une lecture attentive du code, avec la référence indiquée, et doivent être confirmées avant correction. Les numéros de ligne sont ceux du commit `ac6bbbe`, sauf pour les entrées liées à la base Supabase et au collecteur réel (commit `48dd68c`), et peuvent glisser.

Ce qui relève de la feuille de route (authentification, schéma relationnel, client WordPress réel, sauvegardes) n'est pas répété ici : voir la [Synthèse du reste à faire](10-couverture-cahier-des-charges.md#synthèse-du-reste-à-faire).
