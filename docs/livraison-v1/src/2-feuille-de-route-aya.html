Questions de compréhension

QuestionCe qu'on attend
Pourquoi une apostrophe devant la cellule ?Les tableurs interprètent une cellule qui commence par =, +, -, @, tabulation ou retour chariot comme une formule. L'apostrophe force l'affichage en texte. C'est une atténuation, pas une garantie absolue (selon le tableur et le mode d'import).
Pourquoi le bug passait-il avec un tableau ?Le test était conditionné à typeof value === "string" : un tableau d'alias dont le premier élément est =HYPERLINK(…) donnait une chaîne finale dangereuse sans être testé.
Pourquoi -42 n'est-il pas préfixé alors que "-42" l'est ?Un nombre ne peut pas porter de formule ; le préfixer abîmerait les données numériques. Une chaîne peut, elle, venir d'une saisie utilisateur.
Certains tests utilisent toContain("'"). Est-ce suffisant ?Non : ce test passerait même si l'apostrophe était ailleurs dans la ligne. Mieux vaut toBe(…) sur la ligne complète. À améliorer si le temps le permet, non bloquant.

Questions de compréhension

QuestionCe qu'on attend
Pourquoi redirect: "manual" ?Sinon fetch suit les redirections tout seul, sans revalidation : une adresse publique pourrait rediriger vers 127.0.0.1 ou 169.254.169.254 (métadonnées d'un serveur cloud). C'est l'attaque SSRF.
Pourquoi un seul délai pour toute la chaîne ?Avec un délai par requête, 5 redirections de 15 s chacune bloqueraient la collecte 90 s. C'était l'exercice 4a.
Pourquoi lire le corps en flux ?res.text() charge tout en mémoire : un serveur malveillant ou défaillant peut envoyer des gigaoctets. Le flux permet de couper à 2 Mio.
Pourquoi URL_REFUSED n'est-il jamais réessayé, et TIMEOUT oui ?Un refus de sécurité donnera le même résultat à chaque essai et coûte un essai facturé ; un délai dépassé peut être passager.
Qu'est-ce que le DNS rebinding, et pourquoi la PR ne le règle pas ?Un nom public dont la résolution renvoie une adresse privée. La PR vérifie le nom écrit dans l'adresse, pas l'adresse IP obtenue. Cloudflare Workers bloque en pratique les adresses privées, ce qui limite le risque ; une vraie parade demande une résolution DNS maîtrisée, prévue en V1.1.
Le 5 novembre, un test a été supprimé, puis rétabli le 6 : qu'avait-il de faux ?Il attendait une erreur sans code ; la règle retenue est « toute erreur porte un code ». Le test a été gardé et son attendu corrigé. Bonne occasion de rappeler : on ne supprime pas un test qui gêne, on comprend pourquoi il échoue.
Quel cas légitime bloque HOST_MISMATCH, et que fait l'administratrice ?Un site qui redirige societe.com vers societe.fr ou vers blog.societe.com. Elle remplace l'adresse de la source par l'adresse finale.
